# Linux Home Lab

To repozytorium zawiera moje praktyczne projekty związane z nauką administracji systemem Linux wykonywane w środowisku Ubuntu Server.

Celem repozytorium jest dokumentowanie mojego rozwoju w administracji Linuxem, sieciach, bezpieczeństwie, skryptach Bash, Dockerze, Git oraz innych technologiach związanych z serwerami.

## Środowisko

* Ubuntu Server
* VirtualBox
* Bash
* Git i GitHub

## Projekty

Do tej pory wykonałem projekty związane między innymi z:

* instalacją i podstawową konfiguracją Linuxa
* użytkownikami, grupami i uprawnieniami
* konfiguracją SSH
* firewallem UFW
* zarządzaniem pakietami APT
* Netplanem i statycznym adresem IP
* automatyzacją zadań Cron
* logami systemowymi journalctl
* monitorowaniem miejsca na dysku
* wyszukiwaniem plików i tekstu przez find i grep
* monitorowaniem i zarządzaniem procesami
* archiwizacją i kompresją
* potokami i przekierowaniami
* zmiennymi środowiskowymi
* dowiązaniami symbolicznymi i twardymi
* grupami i bardziej zaawansowanymi uprawnieniami
* skryptami Bash
* argumentami skryptów Bash
* podstawami Dockera
* podstawami Gita
* GitHubem i zdalnymi repozytoriami
* logowaniem SSH przez klucze i podstawowym zabezpieczeniem SSH

## Struktura repozytorium
