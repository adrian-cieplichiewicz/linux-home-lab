# Linux Home Lab

[Polska wersja](README.pl.md)

This repository contains my practical Linux administration learning projects created in an Ubuntu Server home lab environment.

The goal of this repository is to document my progress in Linux system administration, networking, security, Bash scripting, Docker, Git and other server-related technologies.

## Environment

* Ubuntu Server
* VirtualBox
* Bash
* Git and GitHub

## Projects

So far I have completed projects covering:

* Linux installation and basic system configuration
* Users, groups and permissions
* SSH configuration
* UFW firewall
* APT package management
* Netplan and static IP configuration
* Cron automation
* System logs with journalctl
* Disk space monitoring
* File and text searching with find and grep
* Process monitoring and management
* Archiving and compression
* Pipes and output redirection
* Environment variables
* Symbolic and hard links
* Advanced permissions and groups
* Bash scripting
* Bash script arguments
* Docker basics
* Git basics
* GitHub and remote repositories
* SSH key authentication and basic SSH hardening

## Repository structure

* "notes/" - notes from each project
* "screenshots/" - screenshots documenting project results
* "project-XX/" - files created during individual projects
